# Hierarchical-Metric-Semantic-SLAM-Methods-for-Architectural-Mapping

This project is made up of two repositories

### eval_repo

Contains the stored graphs and evaluation code used to generate the results from the final report.

### practical_repo

Contains instructions for running the methods used to produce the graphs. This is not required to reproduce the report results, as the stored graphs are already included in eval_repo.

Each repository has its own README with more detailed instructions
